# Code of Conduct

FavRepos welcomes evidence-based, respectful collaboration.

Contributors and maintainers agree to:
- Treat people with respect regardless of background or experience.
- Debate claims with sources and reproducible observations instead of personal attacks.
- Disclose relevant affiliations or sponsorships when recommending resources.
- Avoid harassment, doxxing, discriminatory speech, spam, and knowingly misleading findings.

Maintainers may edit, close, or remove content that violates these expectations, and may restrict repeat offenders. Report concerns privately through the maintainer's GitHub profile or a private channel if supplied. Do not disclose sensitive reports in public issues.
