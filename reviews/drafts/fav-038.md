## Why it matters

HeyGen Skills is an Agent Skills collection that instructs compatible AI agents to use HeyGen for avatar creation, video generation, and translation. It supplies three documented skills and associated instructions and assets. The collection itself is not a video-generation service; successful outputs depend on an agent, an authorized HeyGen account, and a hosted API or remote MCP connection.

## Architecture and classification

**Classification:** Agent Skills collection with optional agent-plugin packaging. The repository tree includes `.claude-plugin`, `.codex-plugin`, `.cursor-plugin`, three skill directories, OpenClaw platform material, install instructions, assets, version metadata, and an MCP configuration file. The three skills cover: (1) avatar creation, (2) script-to-video generation, and (3) translation/dubbing of existing video. The README describes persistent avatar identity metadata saved in local Markdown files for reuse by later skills.

The collection documents a current v3 Video Agent workflow. Statements about “175+ languages,” 20 styles, and particular generation outcomes are author documentation or examples, not independent tests. Older v1 skills are separately identified as legacy material. A shell script for checking versions is documented as optional/read-only; the actual video operations use CLI commands or remote MCP calls.

Codex support is explicitly documented through `gh skill install` and a `.codex-plugin` manifest. This provides stronger evidence than generic Markdown portability. It still requires a compatible Codex environment and service authorization; no installation or operation was tested. The optional HeyGen MCP is a separate remote service, not an MCP server implemented by the local skills repository.

## Requirements and integration

- **Agent:** a skills-compatible agent; README names Codex, Claude Code, OpenClaw, Cursor, and additional runtimes.
- **Install:** README documents GitHub CLI v2.90+ for `gh skill install`; alternate ClawHub, OpenClaw plugin, and clone paths are described. No install command was run.
- **Service authentication:** either HeyGen API key used by the HeyGen CLI or remote HeyGen MCP with OAuth. Skill presence does not create an account, grant permission, or supply credits.
- **Runtime:** skills are instruction folders and README says no build/runtime packages are needed for the skill itself. The CLI is a separate static binary. MCP is hosted remotely.
- **Costs:** API-key mode may use separately metered API credits; MCP mode may consume plan credits. Availability and price depend on account terms and current plan. No amount is estimated.
- **Codex:** explicit documented installer target and plugin manifest; no hands-on discovery, tool call, or API test.

## Security, privacy, and license

The documented workflows can upload a person's photo, video, voice, or other source material to HeyGen and create persistent digital identities and generated videos. Such materials can be sensitive biometric/identity data. Get appropriate consent and rights from depicted and recorded people, confirm permitted synthetic-media use and disclosure, check platform and organizational rules, and inspect requested upload and publication actions before approval. The README's example asks the agent to create an avatar and video in a conversation; a human should separately approve paid or irreversible service operations and any sharing/publication. Nothing about an installed skill grants publishing rights or API access.

The repository's MIT license covers its own skill content subject to its terms. The service, API, avatars, voices, model outputs, uploaded source media, and third-party assets have separate rights, privacy terms, and service conditions. Review HeyGen's current agreements and account plan before use. The documentation describes OAuth/API key paths but is not a security audit of credential storage or service retention.
