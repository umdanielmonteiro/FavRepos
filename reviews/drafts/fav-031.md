## Requirements and integration
The README documents `npm install` and `npm run dev`, plus build, lint and test commands. `package.json` also contains API scripts (`typecheck:api`, `build:api`, `start:api`), Supabase audit scripts, Vitest and Playwright commands. These commands were not run. No Node.js version is declared in the inspected `package.json`; an exact runtime requirement is therefore unknown. Build-time tooling includes Vite, TypeScript, ESLint and Vitest. The manifest declares React, `@supabase/supabase-js`, Firebase and Vercel Analytics among dependencies, but dependencies alone do not confirm which integrations are active, production-connected, or used for which data.

The README identifies Supabase as the legacy provider for data, authentication and functions. It identifies Hostinger as current production hosting. Google Cloud is a future migration direction, explicitly not implemented in the reviewed description. The README also says environment files are local and should not be versioned. It does not document current provider costs, account requirements, deployment credentials, or an operator-facing API contract. No Codex-specific plugin, skill, MCP server, or CLI integration was established. A package dependency for Claude Code is not Codex integration.

## Security, privacy, and license
The documented surface includes administration and a client hub, and the README describes authentication and data/functions through Supabase. This indicates that access control and customer-data handling are relevant review areas, but the README/package manifest do not establish the correctness of authorization, tenant isolation, row-level security, retention, logging, analytics consent, or deployed secrets handling. The instruction to keep `.env` local is documented; it is not proof of complete secret-management controls. Manifest entries for Firebase, Vercel Analytics, Supabase, and other packages are dependencies, not evidence of live production data flows. A security assessment would require a separate, bounded source review and is outside this non-executing curation pass.

No `LICENSE`, `LICENSE.md`, `LICENSE.txt`, or `COPYING` file exists at repository root in the Git tree verified at the reviewed commit. The package manifest’s `private: true` is not an open-source license. Do not classify this repository as open source; permission to use, modify, or redistribute remains unknown unless separate terms are found. Third-party dependencies retain their own terms. The repo includes agent/configuration files for multiple environments, but no first-party Codex-specific integration was confirmed in the reviewed README or package manifest.
