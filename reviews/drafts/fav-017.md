## Architecture and integration

The documented architecture includes a CLI, MCP server, agent and workflow orchestration, memory backends, skills/plugins and optional integrations. MCP is a protocol boundary between a host and server tools; it is not itself a sandbox. A host may expose selected file or command capabilities to a server, and Ruflo tools may in turn call model providers or other services. The effective permissions depend on the exact tools, MCP client configuration, process identity and approval controls. [R1][R2]

The candidate README describes a Codex MCP path using Ruflo setup and a local stdio MCP server. Separately, it links npm package `@claude-flow/codex` under an image alt-labelled “Codex plugin.” This shows that the README advertises a separate Codex-labelled package, but its contents were not inspected and the README does not establish its host behavior or feature parity. The README explicitly identifies console/mods as Claude Code integrations and says hook support depends on the client. Keep these surfaces distinct: MCP instructions, an advertised npm package, and Claude Code plugins/mods do not demonstrate equivalent functionality. [R1]

## Security, privacy, and license

Enabling tools can create consequential access to local files, shell commands, memory and external services. Before use, inspect each exposed tool's implementation and requested permissions, run with least privilege, protect provider secrets, restrict external network access where feasible, and preserve explicit human approval for file writes or commands. Configuration files may contain credentials; never commit them. MCP does not automatically enforce a sandbox, and no independent security audit was performed. These are operational implications, not claims that a particular vulnerability was found. [R1][R2]

Mutable-branch package metadata observed earlier identifies MIT for the package; candidate license/package files were not retrieved to reconfirm it. Separately downloaded dependencies, models, integrations, templates and content can have their own terms. Verify those components in the selected release. [R2]
