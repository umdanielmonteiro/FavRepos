## Why it matters
This is a collection of text-based agent skills for B2B revenue operations and go-to-market work. It is not a CRM, SaaS application, plugin service, or automated RevOps system. The README describes reusable playbooks and frameworks for operators; possible users include sales operations, marketing operations, customer success operations, and GTM teams across B2B businesses (inference).

## Requirements and integration
The documented installation copies selected folders to a Claude project’s `.claude/skills/` directory or uploads skill archives through Claude app settings. The upstream specifically documents Claude Code and Claude apps; no Codex-specific manifest, installer, plugin, MCP server, scripts, hooks, or Codex integration is documented in the inspected README. Codex can read Markdown instructions, but that alone does not mean a Claude skill is installed, auto-discovered, or fully compatible. There is no uniform runtime requirement stated. Individual playbooks may reference HubSpot, Salesforce, data providers, CRM data, benchmarks, or external tooling; credentials, costs, and side effects depend on actions an agent or operator separately configures and authorizes. Reading the files requires no account. The skill’s recommendations are not themselves proof that a CRM action occurred.

## Security, privacy, and license
Plain-text instructions may shape agent behavior and should be reviewed before installation. A skill library does not itself establish permission boundaries for connected tools. Work involving CRM records, customer data, compensation, personal data, or enrichment providers can expose sensitive commercial/personal information; use least privilege, approved data, and human review for external writes. The inspected docs do not specify provider data retention or telemetry because no single inference provider is required by the directory. Repository MIT terms apply to repository material; verify terms attached to separately sourced benchmarks, frameworks, and references. Upstream calls skills “battle-tested”; that is a maintainer claim and not independently demonstrated here.
