## Why it matters

DeskcommCRM combines a CRM and chat-support workflow with WhatsApp connectivity and AI agents. Its documentation describes a Next.js application, Supabase-backed multi-tenant data layer, WAHA Plus/Noweb WhatsApp Web automation engine, distinct from Meta Cloud API, event-driven workers, an MCP endpoint, and AI/RAG functions. Sales and customer-support uses across service businesses are plausible sectors by inference, not evidence of legal compliance or fit.

## Requirements and integration

The project package metadata requires Node.js 22+. The production setup guide describes Docker Compose on a VPS, Supabase PostgreSQL/Auth/Storage, a domain and open HTTPS/SSH ports, and an AI provider key; it recommends 4 GB RAM, noting seven containers and WAHA session memory. Redis is used for rate limiting/RAG debounce, with an in-memory fallback described. Vercel AI Gateway, Supabase, Sentry, Resend, and optional Nuvemshop add external service configuration and possible charges. The setup scripts can install Docker, alter server configuration, pull images, and create services; none was executed.

MCP is explicitly listed at `/api/mcp` with bearer tokens and CRM tools. This is a protocol integration; no first-party Codex-specific setup file or Codex plugin/skill was verified. Repository `.codex` paths are present in the current tree listing but their contents and role were not audited, so native Codex compatibility remains unknown.

## Security, privacy, and license

The data flow can include personal information in contacts, WhatsApp conversations and media, CRM records, embeddings/RAG, model prompts, and observability. Architecture describes private storage buckets and signed media URLs, RLS, role checks, HMAC webhook signatures, API tokens, and PII scrubbing in Sentry. These statements are not certification. Service-role code paths, public webhook/MCP/cron endpoints, tenant scoping, secrets, backups, retention/deletion, and uploaded media require independent deployment review. The security policy assigns self-host server configuration to the operator.

WhatsApp via WAHA/Noweb is a WhatsApp Web automation path, distinct from the official Meta Cloud API channel. Terms, protocol changes, and account enforcement can create service interruption or account restrictions; Meta Cloud API also has its own policies and fees. MIT is reported by the project; dependencies, WAHA and connected providers retain their own licenses/terms. The README's LGPD positioning is not a compliance assessment.
