## Why it matters

OpenMontage is a repository of instructions, pipeline manifests, and executable media tools intended to let an AI coding assistant conduct staged video production. Potential activities include concept planning, script and scene planning, asset generation, editing decisions, composition, rendering, and publishing workflow preparation. Creative production, marketing, and education are plausible contexts by inference; suitability for any particular production environment is not established here.

## Requirements and integration

The README lists Python 3.10+, Node.js 18+, and FFmpeg; specific composition paths require Node.js/`npx`, Remotion dependencies, or Node.js 22+ for HyperFrames. The setup target installs Python requirements, npm packages for the Remotion composer, Piper, and warms a HyperFrames runtime; this was read only and not run. Local GPU generation is optional and hardware dependent. No single GPU minimum was confirmed.

The tool/provider documentation describes direct credentials and potentially billable services for image, video, voice, transcription, and stock media, including OpenAI, ElevenLabs, Azure, fal.ai, Kling, Runway, Google, Pexels, and Pixabay. Some local alternatives are described, with GPU needs. The agent itself is the coding assistant supplied by the user; the architecture says general-purpose LLM API calls are not made by an OpenMontage Python orchestrator, while media-generation tools call their own provider APIs.

Codex compatibility is documented through `CODEX.md`, which points to shared agent guidance. This is instruction-file interoperability, not an installable Codex skill/plugin, MCP server, or built-in editor interface. No hook integration was verified.

## Security, privacy, and license

The agent may execute local tools, write checkpoints/artifacts, read project media, and send selected data to configured third-party APIs. API credentials are expected in environment configuration; protect `.env` and provider keys. Generated files and intermediate media are persisted under project/output paths. A compromised or misdirected agent may incur provider charges or overwrite/create files. The guide documents budget tracking and user approval thresholds, but their behavior was not tested.

Video and image inputs, generated outputs, templates, fonts, music, stock footage, and model/provider terms have separate rights and restrictions. The repository license is AGPL-3.0; this does not grant rights to media assets or third-party model outputs. The README's royalty-free language is not a blanket rights clearance. The repository's security reporting policy and threat model were not fully audited.

## Editorial verdict

**Not assessed**

**Rationale:** Documentation and selected source structures were inspected, but no hands-on or independent security evaluation was performed.

**Best suited to:** Agent-assisted, human-supervised video production experiments where tools, APIs, costs, source rights, and output are reviewed at each consequential step.
