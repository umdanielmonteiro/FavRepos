## Why it matters

This repository packages two agent-discoverable `SKILL.md` workflows: a realtime conversational digital human and a non-interactive talking-video generation workflow. The skill instructions orchestrate the `duix-cli` and Duix services; they are not themselves local lip-sync or avatar models.

## Requirements and integration

- **Type:** collection of two agent skills plus shell helper scripts; neither a model nor standalone generation service.
- **Inventory:** exactly two named skills in the documented layout. Each contains `SKILL.md`, English/Chinese documentation and `scripts/duix_run.sh`; no templates or model weights are listed in the repository layout.
- **Integration:** install skill folders in an agent's skills directory and make `SKILL.md` discoverable. Install `duix-cli` from npm. Upstream lists Codex, Cursor, Claude Code, Copilot, Gemini and OpenClaw. No MCP configuration or native Codex plugin is documented.
- **Runtime:** Node.js 18+, macOS/Linux/Windows (WSL) per collection README. The actual generation runs through Duix services; local OS/hardware requirements of those services are not established by this repository.
- **Credentials and cost:** conversation requires `DUIX_APP_ID` and `DUIX_APP_KEY` and custom subscription quota; video generation requires `DUIX_API_KEY` and prepaid credits consumed per task. Exact price and quota depend on linked live plan pages and were not independently checked.
- **Inputs/outputs:** conversation uses a portrait, selected voice/language and optional persona, producing a browser conversation link. Video generation accepts a human video and speech audio and returns an MP4 path; the README lists video formats/resolution/size and audio formats.

## Security, privacy, and license

Both workflows involve human identity media. The conversation workflow uploads a portrait and yields an interactive identity-linked web page; the video workflow sends a person video and audio to a remote generation service. The repository documents explicit user gates for choosing a TTS voice and confirming billing, and for validating assets/confirming video credits. These are described procedural gates, not independently verified technical safeguards or proof of subject consent.

The repository states Apache-2.0. That license applies to the repository's own material as stated by its README; it does not automatically license the separately installed CLI, Duix API, models, voice assets or output rights. Confirm consent, rights to image/voice inputs, retention and service terms before use. Helper scripts are executable and should be inspected and trusted separately before installation or invocation.
