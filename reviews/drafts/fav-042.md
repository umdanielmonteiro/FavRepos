## Why it matters

This repository is a small deployment template for exposing a bundled HyperFrames composition through Modal. Its intended audience is developers who want to study or adapt a serverless rendering pattern with a browser preview, asynchronous render function, status polling and MP4 retrieval. It is a template, not an already deployed or production-hardened service; deployment requires the user to configure and authorize a Modal workspace.

## Architecture and classification

**Proposed classification:** Deployment template. The Python source constructs a Modal image, a Modal app and a named Volume. The web endpoint serves a browser preview and composition assets. A render request starts a spawned function and returns a call ID; the browser polls a status route, then receives a path to the generated MP4. The worker copies a bundled composition to temporary storage, runs the HyperFrames CLI, and copies the output into the Volume.

Documented deployment commands create or configure cloud resources and require `modal setup` authentication. `uv sync` prepares the local Python environment; `modal serve` serves a development endpoint; `modal run` invokes the bundled smoke composition remotely; `modal deploy` deploys the app. The names and comments in the repo are not evidence of successful deployment. The template README's own performance statements are vendor/project claims and were not used as independent benchmarks.

The preview and render endpoints appear unauthenticated at the application-code level. A deployed endpoint could therefore expose the preview and permit render requests unless platform-level access control or additional protections are configured. The GET download endpoint is a predictable route using generated names, and the code does not show expiration or cleanup. These observations warrant review before public exposure, but do not establish actual exposure of a live system.

## Requirements and integration

- **Local setup:** `uv`, Python 3.12 in the container image, Modal CLI/account and authentication. The image includes Node.js 22, FFmpeg, Chrome headless shell and Chromium system libraries.
- **Remote deployment:** Modal app, spawned function, named Volume, CPU/memory/runtime resources. Resource sizes and concurrency policy were not established from the reviewed source. The code sets a 15-minute render timeout; API request/status behavior should be tested against current Modal platform limits.
- **Composition:** bundled directory under `compositions/`; `PREVIEW_COMPOSITION` is configured in Python. README specifies HyperFrames `index.html` composition shape and preview dimensions.
- **Costs:** Modal bills compute/storage/transfer according to current account terms and usage. The README says per-second rendering, but no estimate is made; costs depend on configuration, duration, retries, storage retention and use. Current pricing was not used to estimate a scenario.
- **Codex:** no Codex-specific plugin or agent feature is documented. A coding agent can inspect/edit the template, but deployment needs Modal authorization and cloud resources.

## Security, privacy, and license

The template copies compositions and local assets into an image, renders them remotely, stores outputs in a Modal Volume, and serves media through an endpoint. This can transmit user media to Modal and expose resulting files to anyone who can reach the service unless access controls are separately configured. Review authentication, endpoint visibility, call-ID validation, abuse/rate controls, file retention, storage deletion, log content, upload size limits, request validation and cloud IAM before deployment. The repository source does not establish these controls comprehensively.

Rendering untrusted HTML/JavaScript on a remote worker can execute composition code and fetch referenced remote resources. Verify that inputs and dependencies are trusted and understand their network access. Cloud compute, storage and transfer can incur charges; enforce budgets and limits in the Modal account and the app. Apache-2.0 applies to template source, not Modal platform terms, HyperFrames or other dependencies, user media, fonts, or asset/model licenses.
