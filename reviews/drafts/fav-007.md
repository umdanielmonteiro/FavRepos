## Why it matters

Agency Agents is a collection of role-specific agent instruction files with conversion and installation scripts for multiple coding-agent products. The repository README reports more than 230 agents and provides workflows spanning engineering, design, marketing, operations and other functions. This is a prompt/instruction corpus and integration tooling, not a hosted “agency” or verified autonomous service.

## Requirements and integration

Basic use is reading/copying selected agent files. The documented conversion/installation path uses shell scripts (`scripts/convert.sh` and `scripts/install.sh`) and writes files to the target agent's configuration area; Codex output is under `~/.codex/agents/`. Exact shell/tool prerequisites and compatibility by Codex version are not established here. The scripts are not needed if a curator manually reviews and copies one instruction file.

Codex support is a documented conversion path to custom agents. It is not native MCP support and does not mean the collection has been validated against every Codex client/model. Model use consumes the user's usual tokens and may have additional cost depending on task size and chosen provider. Large or frequently injected agent instructions can increase context usage; no token benchmark was performed.

## Security, privacy, and license

Agent files are natural-language instructions that can influence model behavior; inspect the exact selected file before use, especially for tool-use, data-sharing, or authorization assumptions. The installer can write configuration files into Codex or other agent directories, so review target paths and generated diffs before executing it. This review did not statically inspect every agent or installer path. There is no basis to treat an agent persona as a security control or expert certification.

The repository declares MIT. Individual examples, names, or linked community translations may have additional provenance or terms; verify them when redistributing. No independent security audit was conducted.
