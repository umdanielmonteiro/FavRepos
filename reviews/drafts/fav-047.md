## Why it matters

LongCat Video Avatar 1.5 is a large audio-driven video-generation model checkpoint collection, built on the LongCat-Video codebase. Its model card describes audio-text/image-to-video avatar generation and video continuation, including single- and multi-person workflows. It is distinct from a hosted-only API, but local inference requires substantial downloads and suitable compute.

## Requirements and integration

- **Type:** model weights/checkpoints for video generation, accompanied by official inference code in a separate GitHub repository.
- **Inputs/outputs:** documented tasks include text+audio, image+audio, continuation from video, and multi-person audio modes; model card examples list 480p/720p controls. The exact accepted file formats, duration limits and output encoding should be checked in the pinned code revision.
- **Runtime:** Python 3.10 environment; PyTorch 2.6 with CUDA 12.4 example, `flash_attn==2.7.4.post1`, `librosa`, FFmpeg and project requirements. v1.5 examples use `torchrun --nproc_per_node=2`, distilled sampling, `avatar-v1.5`, and optional INT8 weights to reduce VRAM. No verified minimum GPU model or VRAM requirement was published in the reviewed card; do not infer that INT8 removes the need for capable GPU hardware.
- **Storage/network:** `main` showed 74.9 GB total, with the base model directory alone 31.7 GB. Weights and code must be downloaded before offline inference; authentication/gating was not indicated on the inspected public pages, but availability can change.
- **License:** Hugging Face metadata says `mit`; model card says weights are MIT unless otherwise stated. The code repository, base model LongCat-Video, Whisper encoder, VAE, text encoder, datasets, and third-party components have their own licensing/provenance; no blanket rights should be inferred.
- **Codex:** no native Codex, MCP, or agent plugin documented.
- **Hosted inference/cost:** model page lists hosted provider/library integrations generically, but this review did not verify a specific provider deployment, price, service availability or commercial terms. Local inference does not imply cost-free compute.

## Security, privacy, and license

Local inference can keep reference imagery/audio on the operator's system after setup, but does not by itself establish privacy of download/update or any optional hosted service. Face and voice references are sensitive identity data. Obtain subject consent and rights, disclose synthetic alteration, and assess impersonation/deepfake and downstream distribution risks. The model card assigns responsibility for legal, privacy and content-safety compliance to downstream users and says the model is not comprehensively evaluated for every use.

The model card's MIT statement is more specific than a generic HF badge, but the direct `LICENSE` file was not reachable (404 at the attempted route); verify the actual pinned repository tree and all code/checkpoint component licenses before redistribution or commercial use. Dataset provenance and consent are not established by the reviewed card. No commercial use or redistribution advice is implied by this summary.
