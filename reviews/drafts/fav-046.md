## Why it matters

Duix Mobile is a native mobile SDK family for rendering and driving 2D digital-human avatars from voice/audio, with motion controls. It is materially different from the Duix Avatar desktop video-generation application and the Duix Skills remote-service workflows. Its documentation describes both Android and iOS SDK integration.

## Requirements and integration

- **Type:** Android and iOS SDKs with example applications and downloadable avatar model assets; not a conversational model stack by itself.
- **Android:** Android 10+, `armeabi-v7a`/`arm64-v8a`, Android Studio Giraffe 2022.3.1 Patch 2, SDK module or AAR integration, 8+ CPU cores, 8 GB device memory, at least 1 GB available storage, with 800 MB available for the digital human. Audio inputs include 16 kHz, 16-bit mono PCM and WAV. SDK documentation includes model/config download and decompression flow.
- **iOS:** iOS 12+, Xcode 12+, iPhone 8+, A12+ recommended and at least 3 GB RAM recommended. Integration embeds `GJLocalDigitalSDK.framework`, links AVFoundation and declares microphone usage permission. Local model paths/configuration are required.
- **Network:** Documentation describes offline rendering after resources are downloaded. Initial model/base configuration downloads are explicit. Developers may host/cache those packages themselves.
- **Conversation services:** LLM/ASR/TTS can be separately integrated by the host app; their availability, local/cloud nature, costs and data flows depend on those choices.
- **Performance:** `<120 ms` is an upstream claim attributed to Snapdragon 8 Gen 2, but no benchmark protocol or end-to-end latency definition is provided. The `<1.5 s` About text has no stated hardware or measurement details. Neither is independently reproduced.
- **Codex:** no agent/MCP integration; compatibility is for application development through Android/iOS toolchains.

## Security, privacy, and license

Camera and microphone permissions appear in mobile SDK integration guidance; media/voice may be handled locally by the avatar renderer, while any ASR/TTS/LLM services selected by the host application may send data remotely. The repository includes `PRIVACYSTATEMENT.md`, but this review did not establish its scope relative to the SDK, sample app, model downloads or telemetry. Review that statement, app permission rationale, service contracts and data flows before deployment.

The repository's `LICENSE` is the Duix Community License. It requires attribution/branding for products using redistributed material and a separate license above the stated 1,000 monthly active user threshold. Rights for downloadable avatar weights/assets and third-party dependencies should be checked independently. Do not infer unrestricted app-store redistribution or commercial use from public source availability. Use only voices/images with consent and rights.
