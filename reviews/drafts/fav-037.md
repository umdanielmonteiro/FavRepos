## Why it matters

HeyGen CLI is an official command-line client maintained in the `heygen-com` GitHub organization for the hosted HeyGen video-generation API. It exposes API workflows to people, scripts, and coding agents. It is not a local video-generation engine: video creation, avatar operations, translation, and related processing are requested from HeyGen services.

## Architecture and classification

**Classification:** official API command-line client. The project is written in Go and ships/releases static platform binaries. It maps command groups to HeyGen's hosted v3 API. Inputs can be flags or JSON bodies; stdout is documented as JSON, errors use structured stderr envelopes, and downloads write resulting assets to local paths. These local file operations do not make rendering local.

Documented groups include `video-agent`, `video`, `template`, `avatar`, `voice`, `audio`, `video-translate`, `lipsync`, `webhook`, `asset`, and `user`. Some commands create, edit, delete, upload, or download remote resources. Async creation can wait/poll; API and network failures have documented exit codes. Exact endpoint availability may vary by API account and release.

## Requirements and integration

- **Runtime:** static CLI binary; no separately installed Go runtime is documented for binary users. Building from source would require Go, but source-build requirements were not assessed.
- **Platforms:** macOS, Linux, Windows through WSL, as stated in README. Exact architecture/OS version matrix is not reproduced here.
- **Authentication:** HeyGen API key or documented OAuth flow. Keys may be set in `HEYGEN_API_KEY` or stored under `~/.heygen/credentials`; protect these credentials and avoid logging them.
- **Network/service:** requires connectivity to HeyGen API and asset endpoints. Video generation and related services run remotely.
- **Codex:** terminal invocation can be orchestrated by a coding agent, but CLI use alone is not a native Codex plugin or MCP transport. The separate HeyGen Skills repo describes Codex-oriented use.
- **Costs:** requests may consume API credits or subscription credits depending on auth mode and account. No costs, quotas, rate limits, or plan eligibility are inferred beyond current docs; consult account terms and official pricing before use.

## Security, privacy, and license

The CLI necessarily transmits API requests and may upload source assets or request creation of avatars, voices, and videos. Treat source videos, images, prompts, voice samples, and generated outputs as potentially sensitive personal data. Review HeyGen terms and privacy notices, applicable consents/rights, retention and processing terms, account scopes, and downstream sharing before sending content. Local credentials should be held in a secret manager or protected environment; API keys can be persisted locally by the login flow. Commands for creation, deletion, account, and feedback may have external or billing effects; review request bodies and confirm intent before automation. The CLI README documents analytics opt-out for feedback and an update notice; this review did not inspect telemetry implementation in source.

The CLI source has an Apache-2.0 license. That license does not govern the hosted API, HeyGen service terms, submitted media, likeness/voice rights, generated media rights, or third-party assets. The official [HeyGen terms](https://www.heygen.com/terms) place responsibility for evaluating and using outputs on users and disclaim guarantees about third-party IP claims; the applicable API terms should be checked for an actual deployment.
