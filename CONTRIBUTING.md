# Contributing to FavRepos

Thanks for suggesting a resource or improving an evaluation.

1. Check whether the exact resource already exists in `catalog/resources.json`.
2. Provide the canonical URL and source platform; separate a GitHub organization from an individual repository.
3. Suggest a short original description and provide the first-party source, exact revision or retrieval date, and evidence. Do not paste substantial publisher text unless its provenance and permission to republish are clear. Include category, artifact type, activities, and general industry tags where relevant.
4. If asserting compatibility or requirements, link to primary documentation or a reproducible test.
5. Declare uncertainty. Avoid undocumented security or production-readiness claims.
6. Put editorial opinions in a separate review with date, context and evidence.
7. Do not include secrets, private organizational information, personally identifiable data, or client information.

Maintainers review changes before merging; inclusion does not imply endorsement.
