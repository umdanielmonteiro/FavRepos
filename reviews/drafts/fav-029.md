## Why it matters
FacePoke is a small interactive portrait/head transformation application, rather than a model collection or generic image generator. Its browser UI lets a user load a portrait and manipulate head orientation and facial parameters. Potential professional uses such as concept art, animation prototyping, or marketing mockups are inferences from that interface, not validated workflow claims. It is not a general-purpose production pipeline.

## Requirements and integration
The README documents Git LFS, Python 3.10, Python requirements, Bun frontend dependencies, Linux, CUDA 12.4 and an NVIDIA GPU as the tested environment. It does not specify minimum GPU model, VRAM, disk space, tested image dimensions, latency, throughput or performance guarantees. These are unknown; “real-time” is the project description, not an independent benchmark. A local browser connects to a Python server over WebSockets; in a hosted demo, images are processed on the remote host and therefore leave the user’s device. Self-hosting keeps processing under the operator’s infrastructure, subject to its deployment and logging configuration. There is no documented CLI, general API product, notebook workflow, or Codex-specific plugin/skill/MCP integration. Codex can inspect source, which does not make the application natively integrated with Codex.

## Security, privacy, and license
Portraits are sensitive personal data and face likenesses can be identifying. Users should have permission from the depicted person and a lawful basis for the intended processing; manipulated portraits can be used deceptively, so provenance/disclosure and rights review matter. The inspected documentation does not establish retention, telemetry, access controls, deletion, or hosted-demo data handling. Self-hosting may reduce third-party exposure but does not itself establish privacy controls. Code is MIT; the README separately states restrictions for InsightFace-derived weights. LivePortrait, ComfyUI-AdvancedLivePortrait routines, checkpoints, assets and dependencies can have distinct licenses/terms; verify the actual downloaded files and their upstream terms. No security policy or independent security assessment was identified in the inspected source.
