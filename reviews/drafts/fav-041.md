## Why it matters

This repository provides real HTML-based HyperFrames compositions associated by its maintainers with HeyGen product-launch videos. It can serve as a reference or starting point for designers and developers studying composition structure, storyboards, asset organization and a CLI preview/render workflow. It is a collection of examples and promotional materials, not the HyperFrames engine, a deployed rendering service, or a general-purpose template product with independently verified reproduction guarantees.

## Architecture and classification

**Proposed classification:** Templates / examples. The repository is a set of HTML-native video compositions, storyboards, metadata and binary assets rather than an independent renderer. A README workflow opens a project directory with the HyperFrames CLI for preview and MP4 rendering. Git LFS is used for video, audio, images and fonts, so a text-only checkout may not include assets needed to reproduce the visible result. A composition may also reference external URLs, fonts or resources; project-by-project dependency completeness was not assessed.

The README identifies 20 composition folders and associates several with product launches, demonstrations or branded material. It states that a public video exists for many directories. These are publisher-provided examples and promotional materials, not independent technical benchmarks. One directory name references Codex, but that does not make the repository an agent plugin or prove the example is compatible with Codex.

## Requirements and integration

- **Runtime:** HyperFrames CLI and a compatible browser/runtime; the exact required CLI version is not pinned by the README. Node.js/FFmpeg requirements are inherited from the separate HyperFrames engine documentation and were not re-evaluated here.
- **Assets:** Git LFS to retrieve bundled video, audio, images and fonts. A normal or selective checkout may require extra asset retrieval.
- **Preview/render:** README documents `hyperframes preview` and `hyperframes render` from an example folder, with MP4 output described by the engine project. The commands were not run.
- **Codex:** No special support documented. A generic agent may edit files, but no installer, plugin manifest or skill collection is established.
- **Services:** No required commercial API was established from the README. Individual examples may depend on external assets or services; these were not inventoried for all 20 projects.

No repository was cloned, no Git LFS assets downloaded, no HTML opened, and no CLI preview or render performed. Reproducibility, broken links, visual quality and the state of each media asset remain untested.

## Security, privacy, and license

Opening compositions executes HTML/JavaScript and may load linked resources. Review each example before preview/render, especially remote script/media URLs and any paths that point outside the project. Using Git LFS or downloading remote media is a separate network transfer. The README warns that media, fonts, logos, photos, screenshots, video, audio and third-party software are not covered by the repository's Apache-2.0 license, and that HeyGen and third-party trademarks are not licensed. The code license therefore must not be treated as a republication license for the finished campaigns or their assets. Confirm rights for every input and output.

The repository does not document a security review of each composition, an asset provenance ledger, or a full per-file rights inventory. Public availability of videos or source files does not establish permission to reuse their content.
