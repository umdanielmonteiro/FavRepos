# Documentary comparisons

This directory contains comparisons assembled from evidence already recorded in FavRepos resource records and review drafts. Its purpose is to make documented differences, unknowns, and useful follow-up tests easier to inspect.

## Editorial limits

- A comparison is not a recommendation, ranking, score, endorsement, or declaration of a winner.
- Documentation and vendor statements describe what a project says or documents; they do not establish that a feature works in a particular environment.
- Do not infer relative speed, accuracy, safety, cost, efficiency, compatibility, or production readiness without reproducible tests designed for that question.
- Keep resource code, model weights, dependencies, and user-provided data distinct when discussing licensing or privacy.
- Record the date and exact source revision where available. If a source revision is not pinned, state that limitation.
- Keep unknowns visible. Proposed tests are plans, not results.
