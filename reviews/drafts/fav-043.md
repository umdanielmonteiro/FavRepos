## Why it matters

Super Video Maker is an instruction-led agent workflow bundled with executable Python/JavaScript tools, reference documents and starter Remotion and HyperFrames projects. It aims to coordinate planning, media generation or capture, composition, captions, rendering and quality checks across separate local tools and remote providers. The skill is not itself a video model, hosted rendering service or single end-to-end application; different providers and scripts own distinct parts of the workflow.

## Architecture and classification

**Proposed classification:** Media-production skill / agent workflow with executable scripts and templates. `SKILL.md` directs an agent through intake, story and script preparation, source gathering, assets, assembly, FFmpeg finishing, QC and exports. Supporting material includes multiple playbooks and recipe data; Python tools call provider APIs or perform local tasks; JS projects provide Remotion and HyperFrames starter compositions. The repository's README mentions screen recording, captions and audio treatment, but advertised output coverage should be treated as maintainer documentation rather than independently demonstrated capability.

Provider boundaries matter. HeyGen client source calls the HeyGen v2 avatar/video API and downloads completed media. OpenAI image helper sends prompts and/or local reference images to the image API. A Replicate wrapper calls a model endpoint with prompt/media references and downloads output. The README separately identifies fal.ai as the intended Seedance 2.5 provider and Replicate as legacy Seedance 2.0 fallback; this review did not confirm every current routing path or model availability. FFmpeg, Playwright, browser recording, Remotion and HyperFrames operate locally unless configured services or remote assets are used. Optional S3 transfers are separate cloud storage operations.

The documented procedure includes gates before paid calls and asks for user approval, but agents must still honor that workflow; tool availability or a prompt alone does not enforce cost controls. Several scripts are directly executable and can make network requests, create files, overwrite outputs, retrieve profiles/media, and use credentials. The README calls optional upload support a possible future/optional capability; no automatic publishing is treated as confirmed.

## Requirements and integration

- **Local runtime:** Python 3, dependencies in `requirements.txt` (requests, dotenv, fal client, OpenAI, Replicate, ffmpeg-python, Pillow, boto3, mysql connector, Playwright), plus FFmpeg. Optional JS paths install root/template npm packages and use Remotion or HyperFrames; Playwright may install Chromium.
- **Credentials:** documented variables include HeyGen API key/avatar/voice IDs, OpenAI key, Replicate token, ElevenLabs key and optional AWS credentials/S3 settings. The actual minimum depends on the selected recipe/provider.
- **Remote processing:** HeyGen avatar generation, OpenAI image generation/editing and transcription, fal.ai or Replicate video generation, ElevenLabs voice/music, and optional AWS S3 are separate external services. Input scripts, images, audio, video or prompts may leave the local machine when those paths are used. Costs and service terms depend on provider/account and are not estimated here.
- **Local processing:** FFmpeg captioning/editing, local screen recording, and Remotion/HyperFrames composition/render steps are presented as local tools; external fonts, scripts or APIs may still be used by a particular workflow.
- **Codex:** no explicit Codex target, `.codex-plugin` or Codex-specific installation procedure was identified. Generic shell-capable agent instructions may be adaptable but do not establish compatibility.

## Security, privacy, and license

This skill combines local agent permissions with scripts that can read user files, capture screens, access local history/media, write output directories, make HTTP/API calls, and incur charges. A deployment of this workflow should use narrow project roots, review all commands and destinations, protect `.env` and session material, confirm licenses and consent for images, voice, avatars, screen captures and source footage, and explicitly approve every provider call and upload. Synthetic presenters and personal likenesses require transparent disclosure and appropriate permission. Provider retention, model training use and deletion terms are not settled by this repository.

The skill's own documents describe paid call gates, synthetic-media disclosures and some copyright precautions; these are instructions, not technical enforcement or legal guarantees. The scripts include direct API calls, for example sending scripts and reference images to external providers and downloading generated video. The repository listing did not show an explicit root license, so no license for the skill's own code/content is asserted. Third-party libraries, fonts, models, sample audio, stock media, trademarks and outputs all have distinct licenses and service conditions. Absence of a LICENSE file does not mean the content is freely reusable.
