## Architecture and classification

**Classification:** Agent Skills collection with installation tooling and executable output checkers. It is not a hosted GTM platform or a single MCP server. Each skill has an instruction entrypoint; supporting references, templates, and scripts are separate package contents. The repository also documents a Claude Code marketplace path and a preview-first interactive installer. `skills.lock` is presented as a file inventory and hash manifest.

Categories in the README include ABM, analytics, automation, content/SEO, creative, customer success, demand generation, design, events, founder-led, growth, GTM operations, inbound, lifecycle, management, outbound, partnerships, product-led growth, product marketing, prospecting, sales plays, sales/RevOps, and tools. The exact counts are dynamic and should be understood as the upstream's published inventory at retrieval time.

Codex support is more specific than generic Markdown portability: the README gives `gh skill install` commands selecting `--agent codex` and Codex scope. The instructions still require a compatible external installer and the host's skill discovery behavior. This does not show a native FavRepos-controlled Codex plugin, MCP implementation, or tested outputs. Claude Code plugin integration is separately documented and does not imply it is the same path as Codex skill installation.

## Requirements and integration

- **Runtime:** Agent Skills-compatible agent; GitHub CLI `gh` with skill support is required for the documented `gh skill` route. The repository's alternate installer uses Python 3 and shell. These installation methods were not executed.
- **Contents:** markdown instructions, framework/reference notes, output templates, executable validation scripts, generated indexes, and lock metadata.
- **Services:** individual skills describe LeadMagic and other enrichment APIs, CRMs, Clay, outbound platforms, analytics, and marketing tools. These integrations are not included as live credentials or guaranteed direct connectors.
- **Codex:** documented `gh skill` target and installation commands; no practical compatibility test.
- **Costs:** no blanket cost can be inferred. Enrichment, CRM, AI-model, email-sequencing, and other services may be paid or credit-metered. The repository does not make those external charges part of its MIT license.

## Security, privacy, and license

The skills can contain executable scripts. The documented lead workflows may process names, professional profiles, email addresses, phone numbers, CRM records, and customer information. Some documented command examples write enriched CSV data or push contacts into outbound platforms. These can expose personal or commercially sensitive information and may trigger external actions or per-record costs. Review the relevant skill, script, scopes, service terms, data provenance, consent basis, and destinations before use; maintain human review before outreach or CRM writes.

The repository has an MIT license. Upstream frameworks, research, names, examples, personal data, APIs, and vendor assets retain their own rights and terms. Its security policy requests sanitized private reports and warns against placing secrets or customer records in issues; this is not a security certification.
