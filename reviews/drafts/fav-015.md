## Why it matters

Fish Speech is a speech-generation codebase with CLI, API server and web UI paths. The official documentation describes text-to-speech, multi-speaker generation, voice cloning using reference audio, and model-controlled editing. The README currently distinguishes Drama 3 (35B-A3B, stated as 3B active per token) and S2-Pro (4B parameters). The model size and feature descriptions are maintainer-published claims, not independently benchmarked findings. Potential uses in media production, dubbing, accessibility and education are inferences from the described speech-generation functions. [R1][R2]

The repository software and model weights are separate licensing objects. Current upstream materials identify Fish Audio Community License v1.0 for the software and associated models covered by that agreement, while S2-Pro weights remain under the Fish Audio Research License. Do not assume that one repository-level label automatically licenses every checkpoint, codec, converted weight, dependency or hosted API. [R1][R3]

## Architecture and implementation notes

The repository describes a neural speech synthesis pipeline accessed through Python tooling and exposes inference through command-line, API and web interface modes. Users download model weights into checkpoints; the docs say model type is detected from checkpoint configuration. Fine-tuning or training workflows and audio preprocessing may require extra dependencies and hardware. The inspected current install page focuses on inference/deployment and does not establish the full training matrix for every model revision. [R1][R2]

Reference audio can encode a real person's voice. Capturing, uploading, caching or processing such samples raises consent, retention, access control and impersonation concerns. Local inference can reduce transmission to a third-party inference provider when the operator configures it that way, but downloading weights and using optional hosted/API services still involves external systems. No privacy or security property was tested. [R2][R3]

## Requirements and integration

**Runtime and hardware.** The candidate `pyproject.toml` declares Python >=3.10 and Torch/TorchAudio 2.8.0, while current external install docs consulted 2026-10-18 prescribe Python 3.12, PyTorch extras and audio system packages such as PortAudio, SoX and FFmpeg; these are different evidence layers, and the dynamic docs are not pinned to this commit. NVIDIA CUDA extras are documented. Intel Arc XPU is described for S2-Pro only; Drama 3 is specified as NVIDIA-only. The docs list CPU installation, but CPU inference should not be interpreted as support for every model: Drama 3's minimum GPU table excludes CPU, Apple MPS and AMD ROCm. The page warns that the compile option is unsupported on Windows/macOS unless Triton is installed manually. [R2]

**Inference/deployment.** Weights are downloaded separately. The documentation describes Docker deployment, CLI, API server and WebUI. Model downloads consume disk/network and inference consumes substantial accelerator memory; infrastructure and power costs are deployment-dependent. Fine-tuning and training requirements, dataset rights and supported training configurations require a separate revision-specific review. [R1][R2]

**Codex.** No first-party Codex integration is identified. Codex could potentially invoke a locally installed CLI or call an API through generic host tooling, but that is not the same as a supported Codex integration and was not tested. [R1][R2]

**Costs.** The code and model licenses define limited free use, but cloud GPU compute, storage and optional hosted API services can incur cost. The Community License requires a separate agreement for any Hosted Service regardless of revenue or purpose; commercial permission for covered materials is limited to annual revenue under USD 500,000 and includes additional conditions. Exact availability and price of a commercial/hosted license are not specified in the repository. [R3]

## Security, privacy, and license

The Community License restricts imitating an identifiable natural person's voice without consent or another legal right, deceptive impersonation, certain harmful content, watermark/provenance removal, and training other generative models from covered outputs. It requires downstream safeguards if third-party voice generation is offered. These contractual controls do not technically verify consent or prevent misuse; deployment operators still need access, abuse-reporting and retention controls. Audio references may be sensitive personal data and should not be uploaded to a service without an applicable lawful basis, informed consent and clear retention terms. [R3]

The license permits limited commercial uses below its revenue threshold, subject to definitions and conditions. It bars Hosted Services without a separate written license. The license also specifies attribution and notice requirements for redistribution. S2-Pro weights remain under a different Research License according to Fish Audio; check the exact artifact card and license before any commercial use or redistribution. [R3][R4]
