## Why it matters

Duix Avatar is presented as a desktop video-synthesis application for creating talking digital humans from text, voice, or recorded human references. The upstream README documents appearance and voice cloning, speech recognition, lip synchronization, model management, and local video generation. This is relevant to audiovisual production workflows, but the same capabilities can enable impersonation and synthetic media misuse.

## Requirements and integration

- **Type:** desktop avatar/video-generation application with Dockerized services; not a model-only repository, SDK, or documented public API product.
- **Interfaces:** Electron desktop client. README documents Docker Compose server deployment; a table of “Open APIs” is present, but the interface and authentication details were not fully validated here.
- **Stack:** package manifest identifies Electron 33, Vue 3, Vite, JavaScript, SQLite, Axios and fluent-ffmpeg. The README lists Node.js 18, Docker and NVIDIA container support.
- **Platforms/resources:** Windows 10 build 19042.1526+ and Ubuntu 22.04 are documented. Recommended desktop hardware is Intel i5-13400F, 32 GB RAM, RTX 4070 and NVIDIA drivers; Windows storage guidance is over 30 GB for project data and over 100 GB for service images. Ubuntu guidance also lists over 100 GB. These are upstream recommendations, not independently benchmarked minimums.
- **Network/offline:** initial images and model assets must be downloaded; README estimates about 70 GB traffic for setup. The project describes local operation after setup, but updates, obtaining assets, and any configured APIs may require network access.
- **Codex:** no Codex skill, MCP server or agent integration was verified.
- **Cost:** repository claims free use, but license thresholds apply and third-party components or services may carry separate terms/costs.

## Security, privacy, and license

The upstream describes offline operation, but no independent data-flow or telemetry audit was performed. Treat face video, voice samples and generated identity assets as sensitive personal/biometric data. Get explicit rights and informed consent from people represented in inputs and outputs; consider labeling synthetic media and preventing deceptive impersonation. The README advertises cloning and realistic video synthesis but the reviewed documentation does not establish effective consent enforcement.

The source `LICENSE` is a Duix Community License, not MIT or Apache. It requires attribution/branding for distributed materials or products and says a separate commercial license is required above the stated monthly active user threshold. A separate community model licensing agreement exists; confirm its exact scope and all Docker image/model/asset and third-party notices before redistribution or commercial use. Do not infer that open GitHub visibility means unrestricted commercial permission.
