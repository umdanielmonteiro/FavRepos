## Why it matters

Evolution API is a self-hostable REST service connecting WhatsApp and other messaging channels with CRMs, chatbots, queues, webhooks, and storage. It documents both a Baileys-based WhatsApp Web route and Meta's official WhatsApp Cloud API route. Messaging integration, customer support, and workflow automation are plausible uses by inference; official-platform approval, legal compliance, and production security are not established by this review.

## Requirements and integration

The README requires Node.js 20+, PostgreSQL or MySQL, and recommends Redis. Docker images/compose are documented. Database provider configuration, Prisma client generation and migrations are required for source deployment. Exposed REST endpoints and stored WhatsApp session credentials should be protected behind secure network controls and carefully managed secrets. Operating costs include hosting, databases, storage, queue services, and potentially Meta Cloud API message charges; no workload sizing or cost estimate was independently established.

No Codex-specific plugin, skill, MCP server, or direct Codex integration was found in the reviewed material. It is an HTTP API that other software may integrate with; generic API interoperability is not native Codex compatibility. CRM, n8n, and chatbot integrations are documented separately.

## Security, privacy, and license

This system can process message content, phone numbers, contacts, attachments, session tokens, and account credentials. Baileys/WhatsApp Web sessions and Meta Cloud API credentials have different operators, permissions, policies, and availability risks. The README's use of “official” refers to the Cloud API integration mode; it does not mean the Evolution API project itself is endorsed by Meta. A WhatsApp Web automation path may be affected by protocol changes or provider enforcement. Exposed API keys, instance boundaries, webhook signature validation, event queues, media buckets, and backups require deployment-specific review.

The repository license text states Apache License 2.0 together with additional brand-protection and usage-notification conditions: preserve Evolution branding/copyright and show a visible usage notification in systems that use the API; it says non-compliance may require a commercial license as determined by the producer. Do not characterize this combined text as unmodified Apache-2.0. The legal effect and compatibility of the added conditions require qualified legal interpretation; review the full LICENSE and contact the licensor. Dependencies, Baileys, Meta, third-party services, and media have separate terms. No LGPD or production-security claim is made.
