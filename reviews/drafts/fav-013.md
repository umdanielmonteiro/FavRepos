## Why it matters

Remotion AI Skills are agent instruction files that provide Remotion-specific workflow guidance to coding agents. The official documentation says they are useful with Claude Code, Codex, Kimi Code and Cursor. They cover project creation, React markup, Studio preview, rendering, maps, captions, SaaS architecture, interactivity, documentation lookup, upgrades and browser-based multimedia guidance. [R1][R2]

This resource is documentation for a skill collection, not the Remotion framework itself, an AI model, an MCP server, or a complete video-generation service. The skills guide an agent; rendering still depends on the separate Remotion project, runtime, packages and any services selected by the user. [R1][R2]

## Distribution and use

The official installation instruction is `npx skills add remotion-dev/skills`. Remotion's project creation workflow also offers installation through `bun create video`; its docs show `npx remotion skills add` in a project scaffold flow. These are documented distribution routes, not commands executed in this review. The selected Skills CLI behavior (global versus project-local placement, supported agent discovery and overwrite/update behavior) should be confirmed from that installer at the time of use; this specific page does not fully establish those details. [R1][R2]

The skills are invoked as agent instructions/prompts such as `/remotion-create`, `/remotion-markup`, `/remotion-studio`, `/remotion-render` or `/remotion-docs`. They provide guidance, but do not by themselves install Remotion, supply a model, create video assets, launch Studio or render media. Such actions require a suitable agent host, project files, Node.js/Bun, package dependencies and user-authorized tools. [R1][R2][R5]

## Requirements and Codex compatibility

**Codex.** The official Remotion skills page explicitly names Codex as an intended agent and gives a CLI installation method. Separate Remotion documentation provides a Codex plugin for the ChatGPT desktop app. These indicate documented compatibility at two different layers: reusable agent skill instructions and an independently distributed Codex plugin. The existence of the plugin does not mean it is installed by the skill command, nor does it make this documentation page itself an MCP server or plugin. Neither path was tested. [R1][R4]

**Requirements.** Reading the web documentation requires a browser. Installing skills requires Node.js/npx or the project-scaffolding route documented for Bun. Using the guidance to build/render a video relies on Remotion framework prerequisites, including the documented Node.js/Bun and supported OS constraints; particular skill topics may refer to additional packages or external services. GPU support is not stated as a general skill requirement. [R1][R5]

**Tools and external services.** The skill descriptions mention Remotion Studio/CLI and can guide use of packages or integrations such as mapping libraries. They are not evidence that the skills execute those tools automatically or include provider credentials. External services and framework add-ons remain separately configured, licensed and priced. [R1][R3]

## Security, privacy, and license

Skill files are instructions that may influence an agent's actions. Review their contents and the privileges of the host before installation, especially if an agent can run shell commands, access files, fetch packages or render user media. The reviewed official page describes installation but does not provide a security audit or claim that skills are sandboxed. Treat third-party content and generated prompts as untrusted inputs. [R1][R2]

The skills repository's applicable license should be confirmed from its repository files before redistribution or modification; the documentation page alone does not state a complete license analysis. Remotion framework licensing is separate: using skill guidance does not waive the framework's license, company/render usage terms, codec patent obligations or third-party asset rights. [R2][R5]

## Limitations and maintenance

Instruction quality can drift from current framework APIs, and a skill's recommendation does not prove that a command or package remains valid. The live documentation page was observed on 2026-10-18 and displayed a last-updated date of 2026-10-17. The pinned repository commit `1441a11e95db35443bd76bb318386c0d3ca00053` is an “Update template” revision that changed 50 files, including the instruction collection. The page date is not asserted as the commit's release date. Review current skill contents, package versions, host behavior and framework docs before relying on an instruction. The skills do not replace implementation review, render QA or licensing review. [R1][R2][R6]
