# Draft technical reviews

These files are documentary research notes, not published recommendations or security certifications. They preserve evidence dates, source revisions, claims, and limitations; some source claims and technical details may become outdated. Name files `fav-XXX.md` and reference the catalog's immutable resource ID. Use the [review template](../REVIEW_TEMPLATE.md).

Browse the complete catalog in the [navigable catalog index](../../catalog/README.md); this page intentionally does not duplicate its resource list.

Personal impressions must come from actual experience and be labeled as opinions. If no test was performed, state **Not tested**.
