## Why it matters

PersoDub is a desktop video-dubbing and media-processing application that combines local AI components with optional hosted services. Its documented activities include speech transcription, voice-preserving translation and synthesis, subtitle editing, audio separation, subtitle erasure, and video/audio/subtitle export. It may be relevant to video localization, accessibility, education, and media production; these sectors are inferred from the functions, not assessed for suitability.

## Architecture and classification

**Classification:** Electron desktop application with local AI processing and optional hosted-provider routes. It is neither a library nor simply a browser app. The documented pipeline separates vocals/background audio, transcribes speech, translates text, synthesizes speech in speaker-specific voices, then aligns and exports media. Documentation names Whisper for ASR, CAM++ for diarization/voice identity, Qwen3-TTS for voice synthesis, Demucs and Mel-Band RoFormer for separation, and Hunyuan/Gemma for local translation; provider choices can change which data leaves the device.

The README advertises 10 local languages and 100+ with its Perso API, while older README snapshots and documents have different counts. Language totals are dynamic author claims and were not independently enumerated or tested. Comparisons to ElevenLabs, HeyGen, and Rask are positioning, not evidence of feature or quality parity.

## Requirements and integration

- **Desktop:** Apple Silicon Mac, macOS 11 or later; or 64-bit Windows 10/11. Windows GPU acceleration is documented for NVIDIA; AMD/Intel graphics are not accelerated according to the FAQ. CPU fallback is documented as slower.
- **Memory/storage:** documentation recommends 16 GB RAM, calls 24 GB comfortable, and specifies at least 30 GB free disk (40 GB on Windows with NVIDIA). Model downloads vary by platform/configuration and can be multi-gigabyte.
- **Software:** shipped desktop shell provisions its Python/PyTorch kit; Python project metadata requires Python `>=3.11,<3.13`. Build-from-source instructions refer to Git, Node.js preparation, and an install script. These instructions were inspected but not run.
- **Optional providers:** Perso API can upload the video; ChatGPT and Gemini can receive transcript text; provider-specific keys or user sign-in may be required. The privacy guide describes these paths and local alternatives.
- **Codex:** an optional Dub Agent invokes the user's installed Codex CLI. It is a documented subprocess integration with its own vendor data flow and stated sandbox behavior, not a native Codex app plugin.
- **Costs:** local inference has hardware, electricity, download, and storage costs. Perso API and external model/service usage can have provider-specific charges or credits; no prices were estimated.

## Security, privacy, and license

Voice cloning and translated media can impersonate real people or mislead viewers. Use only voices, images, videos, and source materials for which the operator has appropriate rights and consent; comply with applicable law and platform disclosure rules. The README advises disclosure of synthetic audio in current docs, but there is no independent compliance evaluation here.

The privacy guide documents several paths: with local engines and a local translator, media can remain on the device; default ChatGPT translation sends transcript text through the user's own OpenAI account; Gemini receives transcript text; Perso API can receive the whole video. It also describes update checks, usage telemetry, and failure reports with machine metadata and log excerpts/archive, with settings to disable analytics and reports. The docs claim filtering of paths/keys; that mitigation was not independently validated. Optional Codex use sends the job script and anything the Codex CLI reads to OpenAI, while its documented filesystem/network restrictions should be reviewed against the actual local configuration.

AGPL-3.0-or-later applies to application code. Model checkpoints, third-party libraries, synthetic voices, input media, and cloud services have separate terms. Voice/model usage rights and commercial permissions remain unresolved without checking each exact model card and provider agreement.
