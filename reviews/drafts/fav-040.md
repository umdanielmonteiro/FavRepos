## Why it matters

This repository collects specialized, independent agent skills for HyperFrames workflows. It may be useful to users who want more focused creative recipes than the core curated distribution provides. It is not an application or rendering engine: skills are instructions plus optional scripts, references and assets. The HyperFrames CLI and other stated tools perform the actual rendering, while skills may request local data, network access or paid service calls.

## Architecture and classification

**Proposed classification:** Skill collection. The eight entries have their own `SKILL.md` files with workflow-specific instructions and, in some cases, scripts, references or assets. Examples include 3D captions, personal-history films, screen composition, p5 painting animation, Strudel music visualization, explainers and X profile cards. Skills may scaffold project files and invoke HyperFrames CLI or other local tools; certain workflows explicitly download dependencies or media. They are not a standalone rendering application and do not share a universal runtime.

The README's documented installation path uses the third-party `skills` installer (`npx skills add ...`) and says the user can select agent targets; there is no root skill or common runtime dependency. Compatibility must be assessed per skill and per agent. One skill explicitly reads Codex session history, but that alone does not establish that all skills load natively in Codex. No Codex plugin manifest was identified in the inspected repository root.

## Requirements and integration

- **Base:** A skills-compatible agent and HyperFrames CLI for workflows that render HyperFrames compositions.
- **Per-skill requirements vary:** inspected instructions specify combinations of Node.js, Python, FFmpeg, Chromium/Puppeteer, npm packages, fonts, WebGL, and sometimes external network endpoints. For example, `p5-paint-animation` lists Node.js, FFmpeg and Chromium disk usage; `session-story` describes reading local agent transcripts; `x-posting-license` loads GSAP remotely from jsDelivr.
- **Codex:** A Codex-related local session path is documented in `session-story`. The generic installer allows agent targeting, but explicit current Codex target support and successful installation were not established.
- **Accounts and costs:** Some community skills are local-only according to their docs; others can make network or paid calls. Each skill's `SKILL.md` must be inspected independently. Do not infer a shared billing or privacy model.

## Hands-on evaluation

No skill was installed, setup script run, command executed, project scaffolded, transcript accessed, file changed outside this review, remote service contacted, API called, or render created. Procedures and QC gates are author-documented and were not practically tested.

## Security, privacy, and license

The collection itself warns that skill instructions may cause an agent to execute commands, read files, access network services or spend money. One reviewed workflow reads local user transcripts and memories; another uses public profile data and downloads an avatar; several write project materials; some load remote dependencies or media. Agent skill documents are executable instructions in the operational sense even when scripts are absent. Inspect each full instruction and script, restrict directory access, validate output paths and inputs, and explicitly approve sensitive reads, uploads, paid calls and publication.

The repository's Apache-2.0 license applies to repository content identified as licensed. Individual skills name separate package, font, model, sample and media rights; X branding is used in one parody/fan template and does not grant trademark permission. Do not assume that skill documentation clears rights to a generated film's source clips, user history, photos, music or fonts. The repository's validation and code-owner processes are not a security certification.
